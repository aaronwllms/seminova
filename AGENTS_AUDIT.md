## Executive summary

- Budget: **266 lines / ~13k tokens**, loaded on every request (**66 lines over the 200-line mechanical trigger**)

- **AG007–AG017**: `§ Implemented now` (~20% of file lines, 150+ path citations) is a feature inventory most tasks never touch — highest budget waste

- **AG001**: Total file size alone fails the budget standard — severity scales with the 66-line excess
- Hard constraints, agent workflow gates (once AG025 is fixed), change protocol, and merge checklist **earn** every-request load — protect those through any slimming pass
- **AG021 resolved**: `docs/mockups/archive/` now exists on disk (was missing at 2026-08-06 audit; 11 archived mockups)

Same class of fragility as auth-boundary; not a broken AGENTS.md reference today.
