# Test Audit — seminova

Last full audit: 2026-07-06
Last synced: 2026-07-06
Scope: test suite health and adherence to `.cursor/rules/testing.mdc`

## Executive summary

- **Suite is healthy overall:** 66 files, 266 tests, all green; global coverage ~91% lines / ~85% branches — comfortably above the 80% CI floor.
- **Highest-risk gap:** `listUsersAction` (admin user listing) has no action-layer tests — only promote/demote are covered; the table mocks the action entirely.
- **Security utilities with thin coverage:** `isSafeRedirect` missing the invalid-URL catch path; `uploadUserAvatar` missing storage-failure and session/userId-mismatch paths.
- **Over-testing cluster:** six marketing landing smoke tests mostly assert config copy renders — low bug-catching value relative to maintenance cost.
- **Convention drift:** several externally-mocked server/auth components use `.unit.test` suffix; one test asserts a Tailwind class instead of user-visible behavior.
- **MSW scaffold is idle:** global `server.listen()` runs on every test, but `handlers` is empty — all boundaries use `vi.mock` instead.
- **Speed:** ~15 UI tests exceed Vitest's 300ms slow threshold; none flaky, but CI wall time is front-loaded on form/table integration tests.
- **Verified strong areas:** auth forms (integration), proxy auth boundary (25 tests + hard-constraint script), profile mutations, and security helpers (`extract-auth-form-error`, `avatar-cache-bust`) are well targeted.

## Verified OK / looks bad but is fine

- **`extract-auth-form-error.unit.test.ts` (8 tests, 134 lines):** Looks like enumeration overkill, but maps a security-sensitive override table with logging contracts — appropriate depth per `testing.mdc` exception for auth sanitization.
- **`proxy.unit.test.ts` (25 tests, 217 lines):** Large, but auth boundary is a hard constraint enforced by `check:auth-boundary` — breadth is intentional.
- **`avatar-cache-bust.unit.test.ts` (10 tests):** Covers host spoofing and cross-user path rejection — security utility, not redundant validation permutations.
- **`profile/actions.unit.test.ts` (11 tests):** Exercises partial updates, avatar URL ownership rejection, and fault paths — matches trust-boundary needs.
- **`scripts/**`tests outside coverage include:**`vitest.config.ts`scopes coverage to`src/\*\*`and`proxy.ts` only — script checks are tested but don't affect the 80% gate; intentional.
- **Page/layout exclusions:** `page.tsx` and `layout.tsx` excluded from denominator — documented in `testing.mdc`; not threshold gaming.
- **No quarantined skips, no snapshots:** ESLint `seminova-test/no-unquarantined-skips` and snapshot ban are clean across the suite.
- **`list-admin-users.unit.test.ts`:** `_lib` pagination/filter logic is tested; TS001 is specifically the thin action wrapper + auth orchestration in `listUsersAction`, not missing list logic entirely.
- **`components/ui/sidebar/cookie.unit.test.ts`:** Tests owned cookie-parsing logic colocated in the sidebar primitive — reasonable unit scope despite `ui/` coverage exclusion.
